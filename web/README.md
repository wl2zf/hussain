# منصة توصية زيوت مركز الفنية

هذا المستودع يحتوي على النسخة الأولية (MVP) لتطبيق ويب تقدّم توصيات زيوت المحركات باللغة العربية مع ربطها بالمخزون الحالي لمركز الفنية في ليبيا.

## نظرة عامة

- **الواجهة**: Next.js 14 مع Tailwind CSS وتصميم عربي من اليمين لليسار.
- **المحرّك**: محرك قواعد مضمّن يعتمد على بيانات رسمية للمركبات ويعدّل اللزوجة وفق ظروف المناخ والاستهلاك.
- **المخرجات**: ثلاث أسطر توصية جاهزة للمشاركة + قائمة منتجات مطابقة من المخزون.
- **الخصائص**:
  - تخزين محلي للتوصيات السابقة للعمل دون اتصال.
  - توليد بطاقة HTML قابلة للطباعة أو المشاركة.
  - زر مشاركة مباشر عبر واتساب.
  - إعدادات PWA (manifest + service worker عبر `next-pwa`).

## الأوامر المتاحة

> **ملاحظة**: قد تتطلب الأوامر تنزيل الحزم من npm. في بيئات بدون إنترنت يجب تثبيت الحزم مسبقًا أو استخدام مرآة محلية.

```bash
npm install
npm run dev
npm run build
npm run start
npm run lint
```

## الخطوات القادمة المقترحة

1. ربط قاعدة البيانات (PostgreSQL) والمخزون الفعلي عبر Prisma أو Supabase.
2. إنشاء لوحة تحكم لإدارة القواعد والمنتجات مع نظام صلاحيات متعدد المستويات.
3. توليد بطاقة PDF مع رمز QR باستخدام مكتبة مولّد PDF وQR مدمجة.
4. بناء API مستقل (NestJS أو FastAPI) لدعم تكامل واتساب وERP.
