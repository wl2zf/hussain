# CipherForge ✦ بوابة التشفير

تطبيق تشفير وفكّ تشفير شامل يعمل **كموقع ويب** و**كبرنامج سطح مكتب (EXE)**.
يدعم أربع خوارزميات تشفير، ويغطّي النصوص والملفات والصور والصوت حتى 50MB،
بواجهة عربية بتصميم داكن أنثوي راقٍ مع خلفية Matrix متحرّكة.

## ✦ المميزات

- **أربع خوارزميات تشفير:**
  - `AES-256-GCM` — متماثل سريع مع توثيق مدمج (يعتمد كلمة مرور)
  - `RSA-OAEP-2048` — هجين: RSA يشفّر مفتاح AES، وAES يشفّر البيانات (زوج مفاتيح)
  - `ChaCha20-Poly1305` — متماثل حديث مع توثيق (يعتمد كلمة مرور)
  - `Triple-DES-CBC` — مع Encrypt-then-MAC بـ HMAC-SHA256 (يعتمد كلمة مرور)
- اشتقاق المفاتيح بـ **scrypt** (N=16384).
- دعم النصوص والملفات (حتى 50MB).
- حماية بـ `helmet` و `express-rate-limit`.
- واجهة عربية احترافية + توليد مفاتيح RSA بضغطة زر.

## ✦ المتطلبات

- [Node.js](https://nodejs.org/) إصدار 18 أو أحدث.

## ✦ التشغيل كموقع ويب

```bash
npm install
npm start
```

ثم افتحي المتصفح على: <http://localhost:3000>

## ✦ التشغيل كبرنامج سطح مكتب (Electron)

```bash
npm install
npm run electron
```

## ✦ بناء ملف EXE (على نظام Windows)

```bash
npm install
npm run dist
```

سيُنتَج المثبّت والنسخة المحمولة داخل مجلّد `dist/`.

> ملاحظة: بناء ملف EXE لويندوز يتطلّب تشغيل الأمر على جهاز **Windows**.

## ✦ طريقة الاستخدام

1. اختاري الخوارزمية.
2. اختاري تبويب **نص** أو **ملف**.
3. للخوارزميات المعتمدة على كلمة مرور: أدخلي كلمة المرور.
   لخوارزمية RSA: اضغطي **توليد زوج مفاتيح** (أو الصقي مفاتيحكِ).
4. اضغطي **🔒 تشفير** — وستظهر النتيجة كنص مشفّر يمكن نسخه أو تحميله.
5. لفكّ التشفير: الصقي **النص المشفّر** في خانة النص، أدخلي كلمة المرور
   (أو المفتاح الخاص لـ RSA)، ثم اضغطي **🔓 فك التشفير**.
   إن كان الأصل ملفًا، سيظهر زر **تحميل** لحفظ الملف المفكوك.

## ✦ هيكل المشروع

```
├── server.js                 # خادم Express
├── main.js                   # تغليف Electron
├── package.json
├── src/
│   ├── services/             # الخوارزميات + اشتقاق المفاتيح
│   ├── routes/               # نقاط الـ API
│   ├── middleware/           # رفع الملفات + معالجة الأخطاء
│   └── utils/                # الثوابت + المغلّف الموحّد
└── public/                   # الواجهة (HTML/CSS/JS)
```

## ✦ نقاط الـ API

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `GET` | `/api/algorithms` | قائمة الخوارزميات |
| `POST` | `/api/keys/rsa` | توليد زوج مفاتيح RSA |
| `POST` | `/api/encrypt/:type` | تشفير (`text` / `file` / `image` / `audio`) — multipart |
| `POST` | `/api/decrypt/:type` | فك التشفير — JSON يحوي `payload` |
